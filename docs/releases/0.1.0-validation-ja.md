## 未検証と利用上の制限

他の Mac への初回導入、root 所有の実際の ReKey の置換、物理入力の解放、実 launchd・XPC の再接続は未検証。
隔離試験のサービスは模擬状態であり、この実機検証の代わりにはしない。
利用者は初回に macOS の「このまま開く」で pkg / app を許可し、入力監視・バックグラウンド項目を設定する。
ad-hoc 署名の更新では入力監視やサービスの再承認が必要になる場合がある。
公式の互換 VirtualHID ドライバの別途導入も必要。
