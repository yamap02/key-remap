macOS 27 / Apple Silicon 向けの ReKey 開発版です。

- 初回導入: `ReKey-<版>.pkg` を開いてインストールしてください。
- 既存利用者: ReKey の「更新を確認」から Sparkle で更新できます。
- `ReKey-<版>.zip` と `appcast.xml` は Sparkle 更新用です。
- 仮想 HID ドライバの導入と macOS の権限設定は別途必要です。

[インストール・更新手順](https://github.com/yamap02/key-remap/blob/main/docs/install-update-ja.md)
